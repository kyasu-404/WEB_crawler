# WEB_crawler

Ищет слова и фразы на страницах сайта по обычным HTML-ссылкам. Поиск ведётся без учёта регистра и выводит одну запись на каждую пару «страница и слово».

## Установка и запуск

Требуется Python 3.11 или новее. Команды для Windows приведены ниже.

```powershell
py -m pip install -r requirements.txt
py crawler.py
```

В Linux и macOS используйте `python3` вместо `py`. Скрипт спросит адрес сайта, слова через запятую и число одновременных запросов. Введите `1` для последовательного обхода или нажмите Enter, чтобы использовать пять запросов.

Для запуска без вопросов передайте все параметры в командной строке.

```powershell
py crawler.py https://example.com -k "приёмная комиссия" -k расписание --concurrency 3
```

Добавьте `--search-link-urls`, если нужно искать также в адресах ссылок.

## Область обхода

- Укажите адрес с каноническим именем хоста, например `www.example.com`, если сайт использует `www`. Краулер обходит тот же хост и сохраняет параметры URL.
- Для адреса без схемы используется HTTPS. Если сайту нужен HTTP, явно укажите `http://`.
- Краулер ищет по тексту полученного HTML. Страницы, которые подгружают текст или ссылки с помощью JavaScript, могут дать неполный результат.
- В конце выводятся счётчики обработанных страниц, редиректов и ошибок. Код завершения `1` означает, что обход встретил HTTP-ошибку, сетевой сбой или недопустимый редирект.
- Если сайт отвечает HTTP `429`, уменьшите число одновременных запросов.

## Проверка

```powershell
py -m unittest discover -s tests
```
